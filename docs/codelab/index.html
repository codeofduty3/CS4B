Ask the Panel

Build a natural-language BDC analytics agent with a typed SQL contract, a guarded MCP server, a replayable LangGraph workflow, and a Streamlit interface.

Python LangGraph MCP SQLite Streamlit
Steps 1. Database and view 2. Guard the SQL 3. Run the MCP server 4. Run the agent 5. Use Streamlit 6. Verify reproducibility 7. Finish
Step 1 · 4 minutes

Build the database and view

Install the pinned environment, then build the generated SQLite database from the committed real BDC panel.

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python tools/build_db.py

The build should report that holdings_v meets its column, row-count, price, and debt-classification contract.

Step 2 · 5 minutes

Guard the SQL

The contract runs static checks before any database request. The server repeats the checks under a read-only connection and SQLite authorizer.

PYTHONPATH=src python - <<'PY'
from askpanel import gate

for sql in [
    "SELECT bdc FROM holdings_v",
    "DELETE FROM holdings",
    "SELECT 1; DROP TABLE holdings",
    "SELECT * FROM sqlite_master",
]:
    try:
        print("allowed", gate.static_check(sql))
    except gate.GateError as e:
        print(e.code, e.detail)
PY
Expected refusals include not_select, multiple_statements, and not_authorized.
Step 3 · 5 minutes

Run the MCP server

Open the server in the MCP Inspector.

mcp dev services/mcp/server.py
ToolPurpose
list_tablesList the closed query catalog.
describe_tableReturn columns and model-facing descriptions.
sample_valuesInspect exact names and spellings.
run_queryRun one gated SELECT.

Every call and refusal writes an audit event. Try SELECT * FROM sqlite_master and confirm that the Inspector reports not_authorized.

Step 4 · 5 minutes

Run the agent

Replay the ten recorded questions without an API key.

python agent/run.py --mode replay
load_schema -> generate -> check -> execute -> summarize
                         ^          |
                         +--repair--+

The cache key includes the model, prompt, schema, history, question, attempt, error, and prior SQL. Changing a request produces a cache miss rather than a stale answer.

Step 5 · 3 minutes

Use the Streamlit interface

streamlit run app/streamlit_app.py

Replay is the default. The screen shows the answer, SQL, visible rows, cost, model calls, tokens, and the full execution trace.

For the follow-up demonstration, ask the q07 question first and then q08 in the same conversation.

Step 6 · 3 minutes

Verify reproducibility

python tests/run_tests.py
pytest -q tests/test_server.py
python agent/run.py --mode replay
PYTHONPATH=src python -m askpanel.check

The clean-clone workflow needs no API key. The agent and application reach data only through the MCP server.

Step 7 · 1 minute

You built the complete loop

SQL is validated before execution. Data access is read-only and audited. Model output is replayable. The interface exposes both the answer and its evidence.
